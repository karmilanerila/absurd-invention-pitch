A one-sentence pitch for the Sock Lighthouse, a ridiculous invention that fixes the tiny everyday annoyance of the sock that always vanishes in the wash: "The Sock Lighthouse sews a miniature lighthouse into every sock, so the one that vanishes in the wash can flash SOS and guide its lonely partner home before the spin cycle eats it." (180 characters, one sentence.)

## Run it

```sh
python3 main.py
```

This writes the sentence to `/output/entry.txt` (or $MAKEFUN_OUTPUT_DIR/entry.txt).
